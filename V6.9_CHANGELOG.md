# v6.9 - Uploaded Artifact Parameter Contract Priority

- Uploaded-artifact bound agents no longer ask durable agent-profile parameters before artifact introspection.
- Runtime input UI now receives the concrete callable parameter contract from the uploaded artifact, such as `city_name`.
- Generic known-parameter aliasing maps existing runtime values such as `location` to callable fields such as `city_name` when applicable.
- Optional callable parameters continue to be non-blocking.
- No business/domain workflow logic is hard-coded; behavior is driven by uploaded artifact inspection and generic parameter aliasing.
