# v6.8 - Runtime Input UI Resume Fix

## Fixed
- Dynamic runtime input UI now renders field metadata as proper form fields instead of raw dictionary text.
- Uploaded artifact parameter requests preserve executable field names, labels, placeholders, aliases, and merge metadata.
- Resume flow now stores submitted runtime parameters in `runtime_parameters`, `runtime_inputs`, and `provided_inputs`.
- Resume flow clears downstream cached execution results and resumes from `execution_preparation` so artifact contracts are rebuilt with user input.
- Optional function parameters do not block execution; only required uploaded-artifact parameters are requested.

## Notes
- No business/domain-specific logic was added to `ai_core`.
- The fix is generic for uploaded artifacts and runtime parameter collection.
