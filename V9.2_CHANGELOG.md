# V9.2 Conversation Context and Memory Layer

## Added
- Generic session persistence layer for conversations.
- Local SQLite/JSONL storage with optional Postgres mirroring through `RUNTIME_POSTGRES_DSN` or `DATABASE_URL`.
- Vector-style memory store with deterministic local fallback and optional Chroma persistence.
- Conversation context window containing recent turns, rolling summary, open items, and boundary status.
- Conversation feedback endpoint that can promote high-quality conversation summaries into local retrieval memory.

## Design
- Postgres stores structured transactional records: sessions, turns, summaries, and feedback.
- Vector memory stores retrievable fragments: compact conversation summaries and approved patterns.
- Runtime-generated data stays under `runtime/` and is not included in source package builds.
