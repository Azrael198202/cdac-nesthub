# v5.0 Workflow Contract / Ranked Execution Decision

## Goal

Rebuild the workflow planning contract so the workflow stage always produces a locked, executable plan before downstream preparation, validation, and execution.

## Key changes

- Added fixed execution option registry:
  - call_llm
  - generate_code
  - generate_shell
  - call_api_no_key
  - call_api_with_key
  - web_query
  - use_external_skill
  - use_existing_tool
  - use_local_knowledge
  - generate_complex_tool
  - compose_static_response
  - ask_user
  - no_op
- Added workflow contract normalizer to guarantee:
  - workflow
  - agent_graph
  - execution_decision
  - planned_steps
  - locked execution_plan
- Updated workflow planning prompt rules:
  - rank fixed execution options
  - select selected_action_type
  - generate agent/substep graph
  - preserve known_parameters
  - do not select concrete URLs/providers/tools in workflow stage
- Updated execution_preparation:
  - prepares prompt/api/web/tool/shell/skill contracts only
  - no workflow execution
- Updated pre_execution_validation:
  - validates action/method/resource consistency
- Updated runtime loop:
  - validation failure loops back to workflow_planning and execution_preparation
  - execution does not run after failed validation
- Added LangGraph stage IO contract file for canonical node order and input/output policy.
