# v6.2 - Uploaded Artifact Reference Resolution

- Added a generic uploaded artifact registry resolver.
- Studio create-agent/create-task now binds explicit uploaded artifacts and filename references in the instruction.
- Delegation context now carries `available_artifacts` and `artifact_binding` to ai_core.
- Agent action normalization preserves referenced artifact records and forces only the generic fixed action `use_uploaded_file` when an available uploaded artifact is explicitly referenced.
- Uploaded artifact preparation can resolve artifact_id/filename references from the runtime registry before inspection.
- No domain/business-specific logic was added.
