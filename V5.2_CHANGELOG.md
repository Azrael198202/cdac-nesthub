# v5.2 Agent Action Prompt Contract

- Added explicit agent_action_planning prompt contract: content, target, fixed actions, and selection rules.
- Added domain-neutral action alias normalization for planner LLM outputs.
- Changed invalid planner output fallback from llm_generate to ask_user to avoid accidental execution.
- Kept selected web/API actions when target/endpoint is incomplete; execution_preparation now marks discovery/preparation required instead of rewriting to LLM generation.
- Workflow planning remains topology-only; agent_action_planning owns final action selection.
