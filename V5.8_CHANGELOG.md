# v5.8 Discovery to API Contract

## Goals

- Treat planner LLM calls as planning/discovery only, not final execution.
- Make `web_query` a discovery phase that can collect pages and API candidates.
- Convert discovered structured endpoint candidates into an `api_contract` before execution.
- Prefer no-credential candidates before credential-required candidates.
- Preserve credential-required candidates and route them to UI credential collection instead of discarding them.
- Execute only the locked prepared URL/endpoint from `execution_preparation` and preserve evidence URLs.
- Keep implementation domain-neutral and avoid business/domain hardcoding.

## Main changes

- Extended `agent_execution_flow` default phases:
  1. planner LLM action selection
  2. resource discovery
  3. API/web contract preparation or credential request
  4. real execution
- Added credential-preserving preparation for external candidates.
- Added generic prepared external resource executor.
- Strengthened validation for credential-required external candidates.
- Added evidence URL preservation for prepared external execution.
