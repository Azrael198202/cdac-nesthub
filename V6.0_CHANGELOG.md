# v6.0 Agent Studio Upload UI

## Added

- Added Agent Studio UI upload panel for external artifacts.
- Added artifact registry viewer and bind checkbox per uploaded artifact.
- Added multipart upload API: `POST /api/agent-studio/artifacts`.
- Added artifact registry API: `GET /api/agent-studio/artifacts`.
- Bound selected uploaded artifacts to create-agent and create-task requests.
- Passed bound artifacts into participant shared context for primary runtime execution.
- Added UI dynamic parameter support for uploaded-artifact runtime parameter collection.
- Restored missing `auxiliary_brain.runtime.new_id` runtime framework helper.

## Design rule

Uploaded files are treated as generic external artifacts/method candidates. The core does not hard-code domain or business behavior.
