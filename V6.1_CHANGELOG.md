# v6.1 - LLM Generation Flow and Runtime Observation Guard

- Clarifies that external discovery/API flows are selected by runtime action planning, not hard-coded to any domain.
- Adds a formal `llm_generate` execution flow: prompt contract, output contract, executor LLM generation, and result verification.
- Adds a generic action-selection guard: direct natural-language deliverables use `llm_generate` unless an executable/reusable artifact is explicitly requested.
- Prevents `generate_code` / `generate_complex_tool` / `llm_generate` from silently falling back to runtime native observation.
- Adds prompt/output contracts to execution preparation for content generation.
