# v23.12 Debugger-safe preflight runner

Fixes a regression where VS Code/debugpy could inject pydevd bootstrap code into generated capability preflight subprocesses. In debug mode the runner may pause inside a dynamic `<string>` before the generated artifact executes.

Changes:

- Detect active debugger/debugpy/pydevd environments before running generated-artifact preflight.
- Use a generic in-process preflight runner with a daemon thread timeout when debugger subprocess injection is active.
- Keep the normal isolated subprocess preflight path outside debugger mode.
- Retry through the in-process runner if subprocess output indicates debugpy/pydevd injection.
- No capability-specific keywords or hardcoded business logic were added.

Verification:

- `python -m py_compile auxiliary_brain/capability_acquisition/code_generator.py`
- Normal preflight smoke passed.
- Forced debugger-safe in-process preflight smoke passed.
