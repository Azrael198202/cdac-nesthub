# Intent Contract and Execution Method Enforcement

## Summary

This version fixes two stage-boundary problems:

1. Downstream workflow normalization could replace the upstream intent with an inferred capability.
2. Execution could ignore the resolved method contract and fall back to external evidence even when a runtime-local method was selected.

## Design

The runtime now applies this chain:

```text
input_parsing
→ intent_recognition
→ intent_contract lock
→ workflow_planning
→ workflow_intent_guard
→ execution_method_proposal
→ deterministic execution_method_resolver
→ execution_method_enforcer
→ tool / web / API / knowledge execution
→ evidence quality validation
→ output
```

## New Components

### `ai_core/workflow/intent_contract.py`

Creates a generic contract from upstream stages:

- intent type
- normalized intent
- parsed entities
- target values
- intent family
- source nodes

The contract is task-neutral. It does not embed concrete business vocabulary. It only uses structural metadata generated by earlier runtime stages.

### Workflow Intent Guard

The guard checks every workflow step before execution:

- Downstream stages may refine an intent.
- Downstream stages may not replace the intent with an inferred conflicting capability.
- Inferred capabilities are weaker than locked intent contracts.
- Runtime-native execution cannot be silently replaced by external evidence retrieval.

### Execution Method Enforcement

The executor now treats the resolved method as a real contract:

- `runtime_generated_tool` with no fallback cannot fall through to web retrieval.
- `web_search` and `api_call` are the only methods allowed to enter the external evidence path.
- Step-level execution method policies are merged into resolver policy.
- A resolved source contract must not be overwritten by generic strategy fallback.

## Evidence Quality Change

If target values were extracted upstream, evidence quality now requires at least one aligned target before passing. This prevents unrelated numeric values from becoming final facts simply because they contain units.
