The forecast.days endpoint returns up to 10 days of forecast information for a specific location, starting with the current day. The API returns the following: A description of the daytime (7:00 AM to 7:00 PM) and nighttime (7:00 PM to 7:00 AM) weather conditions with corresponding icons Daily maximum and minimum temperatures Daily maximum and minimum apparent (\"feels like\") temperatures Heat index Relative humidity UV index Probability, percentage, quantity, and type of precipitation Probability of thunderstorms Sea level pressure Wind chill Wind direction , speed, and gust Ice thickness Visibility and cloud cover Daily sunrise, sunset, moonrise, and moonset times The APIs Explorer lets you make live requests so that you can get familiar with the API and the API options: Try it! About daily forecast requests To request current conditions, send an HTTP GET request to: https://weather.googleapis.com/v1/forecast/days:lookup?key= YOUR_API_KEY & location.latitude= LATITUDE & location.longitude= LONGITUDE Include the latitude and longitude coordinates of the location in your request URL parameters . Daily forecast request examples By default, the forecast.days endpoint returns 10 days of data, starting from the current hour. You can scope your request to a particular number of days using the days parameter.
