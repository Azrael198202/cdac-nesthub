# v23.9 Model Progress + Debug Isolation

## What changed

- Added operator-visible model preparation events:
  - model_prepare_started
  - model_prepare_completed
  - model_prepare_failed
  - model_download_started
  - model_download_completed
  - model_download_failed
  - model_generation_started
  - model_generation_completed
  - model_generation_failed
- Added bounded LLM request timeout through AI_CORE_LLM_TIMEOUT_SECONDS.
- Ollama local exact match is reported as a completed model preparation step, so installed models such as qwen2.5-coder:7b are not treated as downloads.
- Sandbox/preflight subprocesses now strip debugger-related environment variables and set PYTHONBREAKPOINT=0 / PYDEVD_DISABLE_FILE_VALIDATION=1.
- Timeout reports now include an environment note when an IDE/debugger pause may have stopped a subprocess.

## Boundary

No capability-specific implementation logic was added to code_generator.py.
