# V9.1 Changelog

## Runtime-generated script execution hardening

- Keeps automatic third-party Python dependency installation as the primary repair path.
- Runs generated Python artifacts with unbuffered stdout so early results are captured reliably.
- Treats a generated process that exceeds the runtime timeout after producing usable stdout as a bounded runtime result instead of surfacing a raw timeout command as the final answer.
- Adds a generic source-generation instruction that generated scripts must finish by themselves and must not create unbounded loops, background daemons, or indefinite waits.
- Records dependency, timeout, and runtime-bounding metadata in execution result data for debugging.

## Validation

- Added regression coverage for timeout-with-output handling and bounded generated-script prompt rules.
- Runtime output directories are cleaned before packaging.
