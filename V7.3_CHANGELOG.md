# V7.3 - Uploaded Artifact Edit Review + Pre-execution Parameter Collection

## Changes
- Added reviewable uploaded-artifact edit proposals.
- Original uploaded file is preserved until user confirmation.
- Confirmed draft replaces the active artifact and stores original backup metadata.
- Agent Studio UI now supports artifact edit, draft download, feedback/revise, confirm, and cancel.
- Uploaded artifact parameters are inspected before task execution.
- Task-explicit runtime parameters are applied to the current run only.
- Uploaded artifact selections are one-shot and no longer auto-bound after upload.
