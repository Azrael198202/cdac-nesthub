# V8.7 Changelog

## Fixed

- Fixed open-capability agent creation when the runtime LLM cannot infer a parameter contract.
- Agent definitions phrased as reusable abilities now receive a generic runtime `task_input` contract instead of an empty contract.
- Task execution now pauses with a UI parameter request before delegation when required runtime input is missing.

## Regression Coverage

- Added tests for open-capability agent parameter fallback.
- Added tests that executing such an agent task returns `requires_input` with a generic runtime input field.

## Notes

- The fix is structural and domain-neutral. It does not add business-specific parameters or hard-coded task keywords to core runtime logic.
