# V7.9 Command Registry Routing

- Converted Studio command handling to a registry-first model.
- Added default `commands[]` entries with command_id, category, action, patterns, priority, and enabled.
- Updated StudioCommandRouter to match the normalized command registry instead of hardcoded command phrase routing.
- Kept legacy `command_phrases` compatibility.
- Runtime command-set overlays remain under `runtime/configs` and are not part of source artifacts.
- Added runtime update support for `add command "..." as <action>`.
