# V9.0 Runtime Dependency Preparation

- Runtime-generated Python artifacts are no longer replaced only because they import external Python modules.
- Before executing generated Python artifacts, the runtime detects missing external imports and attempts to install the corresponding Python package automatically when install permissions allow it.
- If execution still fails with a missing-module interpreter error, the runtime performs one repair attempt and retries the generated artifact.
- Dependency preparation results are attached to the artifact execution result for traceability.
- The generated-source prompt now permits external Python packages when necessary while still preferring the standard library when sufficient.
