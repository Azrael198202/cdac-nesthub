# V7.7 Uploaded Artifact List / Optional Input Fix

- Removed domain-specific alias logic from uploaded artifact contract building.
- Python callable annotations such as `List[str]` / `typing.List[str]` now produce list-style runtime input fields.
- Optional callable parameters are displayed in the same runtime-input dialog when required parameters must be collected, but they do not block execution.
- UI list fields support multiple values via comma, newline, or repeated add actions.
- Empty optional fields are not submitted as runtime values.
- Uploaded artifact execution preserves list values instead of collapsing single-item lists to scalars.
